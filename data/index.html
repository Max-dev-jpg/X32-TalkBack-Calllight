Available OSC Paths

PathArgumentDescription
Per-Trigger control (N = 1 – 4)
/calllight/trigger/N int 0|1 Activate (1) or release (0) Trigger N. Runs that trigger's actions.
/calllight/trigger/N/on none Activate Trigger N.
/calllight/trigger/N/off none Release Trigger N.
/calllight/trigger/N/pulse int ms (opt.) Momentary: activate Trigger N then auto-release after ms milliseconds (default 300 ms). Re-sending extends the timer.
Legacy paths (Trigger 1 only)
/calllight/trigger int 0|1 Backward-compatible set for Trigger 1.
/calllight/trigger/on none Backward-compatible activate Trigger 1.
/calllight/trigger/off none Backward-compatible release Trigger 1.
Talkback
/calllight/talkback/a int 0|1 Simulate Talkback A. Runs Talk A actions from the Talkback tab.
/calllight/talkback/b int 0|1 Simulate Talkback B. Runs Talk B actions from the Talkback tab.

Trigger actions are configured per trigger in the Triggers tab. Talkback actions are configured in the Talkback tab.
